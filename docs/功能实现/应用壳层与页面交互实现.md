## 2. 双端共用实现

以下组件与机制直接放在 `src/shared/` 下，由桌面与 Android Vite 配置通过别名共同编译引用：

### 2.1 启动电源按钮与呼吸波形动效
- **核心文件**：[DashboardPowerButton.tsx](../../src/shared/ui/DashboardPowerButton.tsx)、[ProxyPowerButton.tsx](../../src/shared/ui/ProxyPowerButton.tsx)、[proxy-power.css](../../src/shared/ui/proxy-power.css)
- **实现机制**：
  - 使用 SVG 多瓣波浪路径（`buildWaveBlobPath` 生成 `CORE_BLOB_PATH`、`MID_WAVE_PATH`、`BACKDROP_WAVE_PATH`）叠加旋转与缩放脉冲动画，提供启停过渡旋转环 `PowerOrbitRing` 与运行态 5 柱声波跳动 `PowerWaveform`。
  - 通过实时的 `uploadRate + downloadRate` 计算归一化活跃等级 `level`，动态调整波形柱高和动画周期（无流量时保持低幅慢速呼吸，有流量时加快跳动）。
  - 提供 `waitForProxyPowerAnimation(action, startedAt)` 确保启动至少保留 `650ms`、停止至少保留 `320ms` 动画反馈，避免内核毫秒级返回导致按钮一闪而过。

### 2.2 平滑常驻滑块分段器（`Segmented`）
- **核心文件**：[segmented.tsx](../../src/shared/ui/segmented.tsx)
- **实现机制**：
  - 放弃每项内部反复卸载/重挂的 `motion.span layoutId` 方案，改为在 `<div role="group">` 容器内放置单个常驻滑块 `<motion.span>`。
  - 通过 `useLayoutEffect` 与 `ResizeObserver` 测量当前选中按钮相对父容器的 `offsetLeft` 与 `offsetWidth`；首次挂载时以 `duration: 0` 就位（不从左上角飞入），后续切换通过 `transform: translateX(...)` 与 `width` 的弹性过渡滑动到目标位置，并遵循 `useReducedMotion()`。

### 2.3 单行可展开消息提示胶囊（`MessageViewport`）
- **核心文件**：[message.tsx](../../src/shared/ui/message.tsx)、[style.css](../../src/app/style.css)、[mobile.css](../../android/web/src/mobile.css)
- **实现机制**：
  - 全局通过 `useSyncExternalStore` 管理最多 5 条通知栈，`showMessage` 推送后按类型设置默认倒计时（`error` 6000ms、`warning` 4000ms、其余 2800ms）。
  - **默认单行紧凑呈现**：默认仅单行展示 `title`（`white-space: nowrap; text-overflow: ellipsis`）并隐藏 `description`；`useLayoutEffect` + `ResizeObserver` 仅在折叠态下检测 `scrollWidth > clientWidth + 1`，当存在超长截断、换行符或 `description` 时自动显示可旋转的 `ChevronDown` 图标。
  - **点击展开与手势关闭**：有额外内容时点击胶囊可切换展开态并暂停自动倒计时（点外部区域或按 `Escape` 收起）；桌面鼠标与手机触控统一放行**向上、向左、向右**跟手拖拽与快速滑动飞出关闭（向下施加 `rubberBand` 阻尼回弹）；触屏提高激活阈值为 `8px`（鼠标 `5px`），避免轻点展开时误触发拖拽。

### 2.4 节点延迟测速按钮（`NodeLatencyButton`）
- **核心文件**：[NodeLatencyButton.tsx](../../src/shared/ui/NodeLatencyButton.tsx)
- **实现机制**：
  - 根据最近延迟区分颜色语义（`<= 500ms` 绿色、`500~1000ms` 琥珀色、`>= 1000ms` 或超时/失败红色、未测蓝色）。
  - 测速中状态（`testing = true`）切换为横向流光层（`.air-latency-shimmer`）与旋转圆环 `ProbeSpinner`，并用 `disabled={testing || disabled}` 防止重复点击同一测速中节点。

### 2.5 多语言管理与折叠语言设置（`LanguagePicker`）
- **核心文件**：[messages.ts](../../src/shared/i18n/messages.ts)、[LanguagePicker.tsx](../../src/shared/i18n/LanguagePicker.tsx)
- **实现机制**：
  - 内置加载 `resources/languages/*.json` 语言包，运行时根据 `activateLanguage` 切换词典与 `Intl` 区域格式；`tr(key, ...values)` 执行 `{0}` 占位符替换，缺失词条自动回退到原文。
  - `LanguagePicker` 支持 `embedded` 模式，分别嵌入桌面与手机「设置 → 外观」卡片的「主题」选项之后；「语言文件夹」路径与「导入语言包」按钮默认折叠收起，点击整行可展开/收起（对 `<AirSelect>` 下拉框包裹事件冒泡隔离 `stopPropagation`，下拉切换语言不会误触折叠）。

### 2.6 配置代码编辑器与搜索栏
- **核心文件**：[ConfigCodeEditor.tsx](../../src/shared/ui/ConfigCodeEditor.tsx)、[EditorSearchBar.tsx](../../src/shared/ui/EditorSearchBar.tsx)、[cmSearch.ts](../../src/shared/ui/cmSearch.ts)
- **实现机制**：基于 CodeMirror 6 封装 YAML 高亮与折叠编辑，配合 `yaml` 库进行语法解析和实时错误数量统计，向外部暴露当前光标行列号与查找高亮导航。

### 2.7 其他共享展示与交互组件
- [ConnectionApp.tsx](../../src/shared/ui/ConnectionApp.tsx)：统一渲染连接记录的应用图标（带文字首字母兜底占位）与进程/应用名。
- [CopySubscriptionLink.tsx](../../src/shared/ui/CopySubscriptionLink.tsx)：复制链接后临时反馈状态。
- [TrafficBars.tsx](../../src/shared/ui/TrafficBars.tsx) & [PageHeaderIcon.tsx](../../src/shared/ui/PageHeaderIcon.tsx)：流量柱状趋势图与页面标题动态图标。

## 3. 电脑版实现（Windows 桌面端）

### 3.1 应用窗口、自绘标题栏与可拖拽分栏
- [App.tsx](../../src/app/App.tsx) 与 [AppTitlebar.tsx](../../src/app/AppTitlebar.tsx)：基于无边框窗口渲染自定义标题栏、当前出口摘要、运行指示器与最小化/最大化/关闭控制。
- [ResizableSidePanel.tsx](../../src/shared/ui/ResizableSidePanel.tsx)：在节点库中为左侧来源分组树与右侧节点/链路检视区提供边界指针拖拽调整宽度并持久化偏好（`preferences`）。

### 3.2 系统托盘与开机自启动
- [tray.rs](../../src-tauri/src/tray.rs)、[artwork.rs](../../src-tauri/src/tray/artwork.rs)、[menu_icons.rs](../../src-tauri/src/tray/menu_icons.rs)：创建 Windows 托盘图标并根据 `running / tun / system_proxy` 状态更新提示；右键菜单通过 Tauri 事件向前端派发启停、模式切换、系统代理与虚拟网卡开关；关闭主窗口默认最小化到托盘而非退出进程。
- [startup.rs](../../src-tauri/src/commands/startup.rs) 与 [StartupSettingsCard.tsx](../../src/features/settings/StartupSettingsCard.tsx)：写入或移除 Windows 当前用户自启动项，同时结合 SQLite 的 `startup_proxy` 记录实现“打开 Air 时自动启动上次出口”。

### 3.3 设置主页滚动位置记忆
[SettingsView.tsx](../../src/features/settings/SettingsView.tsx) 利用模块级变量 `savedOverviewScrollTop` 配合 `onScroll`（仅在 `settingsPage === 'overview'` 时记录）与 `useLayoutEffect`，确保不仅切换内置子页能恢复浏览位置，切换到会卸载 `SettingsView` 的「分流规则」独立组件再返回时也能精准恢复。

## 4. 手机版实现（Android 移动端）

### 4.1 原生 WebView 容器与防浏览器化加固
- **原生壳层（[MainActivity.kt](../../android/app/src/main/java/app/air/android/MainActivity.kt)）**：
  - 使用 `WebViewAssetLoader` 在虚拟同源 `https://appassets.androidplatform.net/assets/` 下安全托管本地前端产物，拒绝外域页面跳转；通过 `WebViewCompat.addWebMessageListener` 建立 `airAndroid` JS-Kotlin 异步消息桥。
  - 关闭浏览器式交互：`setSupportZoom(false)`、`builtInZoomControls = false`、`displayZoomControls = false`、`setGeolocationEnabled(false)`，关闭原生滚动条与过度滚动光晕；配合 [SplashOverlay.kt](../../android/app/src/main/java/app/air/android/SplashOverlay.kt) 实现冷启动渐隐过渡遮罩，拦截系统返回键派发 `air-back` 事件优先关闭抽屉/菜单。
- **前端视口与事件防护（[index.html](../../android/web/index.html)、[mobile.css](../../android/web/src/mobile.css)、[main.tsx](../../android/web/src/main.tsx)）**：
  - `viewport` 锁定 `minimum-scale=1,maximum-scale=1,user-scalable=no`；`html, body` 设 `touch-action: pan-x pan-y` 与 `overscroll-behavior: none`，禁用非编辑区文本选择及图片/SVG 拖拽；
  - 启动时运行 `hardenMobileWebView()` 拦截多指捏合 `touchstart`/`touchmove`、`gesture*`、缩放/保存/打印快捷键、HTML5 拖放与非可复制区浏览器右键/长按菜单（保留节点/订阅/分组卡片的 `onContextMenu` 长按编辑及输入框/编辑器复制粘贴）。

### 4.2 顶栏动态电源联动与底部导航
- **顶栏电源 morph（[app.tsx](../../android/web/src/app.tsx)、[views.tsx](../../android/web/src/views.tsx)、[ui.tsx](../../android/web/src/ui.tsx)）**：首页中监控主卡片电源锚点 `powerAnchorRef` 相对于顶部的滑动进度 `homePowerProgress`，滚动出可视区后平滑放大顶栏右上方迷你电源按钮 `HomeHeaderPower` 并将状态圆点 `StatusDot` 同步左移让位。
- **底部导航（`BottomNavigation`）**：使用共享元素 `layoutId="sidebar-nav-pill"` 配合弹簧过渡切换五个一级标签页。

### 4.3 出站模式无闪烁乐观切换
[app.tsx](../../android/web/src/app.tsx) 中首页出站模式使用独立 `switchMode`，点击后立即更新 React 状态并驱动 `Segmented` 滑块滑动（不再走触发全局 `busy` 灰态的 `task(...)`），后台通过 `enqueueWrite` 顺序执行 `apply` 与 `saveOutbound`；连续点击使用 `modeSwitchToken` 去重，失败时回滚到 `modeRollbackRef` 并弹出错误提示。

### 4.4 实时连接卡触边超滑接管与手势抽屉
- **触边连续滑动接管（[views.tsx](../../android/web/src/views.tsx)、[mobile.css](../../android/web/src/mobile.css)）**：`.home-conn-list` 设置 `overscroll-behavior-y: auto`；同时在 `Home` 中为列表绑定被动触摸监听，当单次手势滑至列表顶部或底部边界并同向继续拖动超过 `20px` 后平滑接管外层 `.page-scroll` 滚动，抬手时通过 `requestAnimationFrame` 执行指数衰减惯性滑动，期间若原生已触发滚动链或用户反向回拉则立即退让。
- **底部抽屉（`Sheet` in [ui.tsx](../../android/web/src/ui.tsx)）**：顶部手柄 `.sheet-handle` 支持向下 1:1 跟手拖拽关闭及向上阻尼回弹，通过 `AnimatePresence` 管理退出动画期间的快照缓存防止内容闪烁。
- **设置滚动记忆（[settings.tsx](../../android/web/src/settings.tsx)）**：`SettingsIndex` 通过模块级 `savedSettingsScrollTop` 与 `useLayoutEffect`，进入子页返回设置主页时恢复上次滚动位置。
