## Air 1.0.0

下载 `Air-1.0.0-windows-x64-setup.exe` 安装到 Windows 10 或 Windows 11 x64 电脑。随附内核要求处理器支持 `x86-64-v2`。打开 Air，导入 Clash YAML 订阅或添加节点，选定节点后点击「启动」。新安装默认启用系统代理。首次使用 TUN 时，在 Air 内确认安装虚拟网卡服务，并完成 Windows 授权。

- 仪表盘可启停代理、切换出站模式，并查看当前节点、出口 IP、实时流量与连接。关闭窗口后可继续从托盘控制代理。
- 支持通过链接、YAML 文件或二维码导入订阅。可管理节点与分组、测试延迟，并设置分流规则和多跳链路。
- TUN 启动前检查当前路由，自动避开已占用的虚拟网段。默认接管常规 DNS 查询，使用加密 DNS，并返回真实 IP。
- 本地混合端口默认优先使用 `7890`。端口被占用时使用空闲端口，待 `7890` 释放后可接收固定访问该端口的本地 TCP 代理连接。
- 「设置 → 关于」可检查更新。应用内更新支持签名校验、增量下载和断点续传。

安装程序目前没有 Windows 代码签名，下载后可用同页的 `SHA256SUMS.txt` 核对文件。安装包附带 Mihomo `v1.19.32` 的许可证和构建信息，对应源码和构建脚本可在上游下载。 [Mihomo 对应源码](https://github.com/MetaCubeX/mihomo/tree/88dcbf7f1614a67c3b36b848ee3592dfa92ada36) · [GPL-3.0 许可证](https://github.com/MetaCubeX/mihomo/blob/v1.19.32/LICENSE)
