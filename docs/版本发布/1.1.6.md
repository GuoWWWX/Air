## Air Proxy 1.1.6

- Windows 首页新增「服务连通性」卡片，默认显示 Google 和 GitHub 的 Logo 及 HTTPS 响应耗时。点击右上角可展开查看包含 YouTube、ChatGPT 在内的四项结果，也可以重新检测。
- Windows 首页新增节点健康、套餐余量和实时分流概览，可从卡片直达节点库、订阅或分流设置。开启代理后可一键复制本地代理地址。
- Windows 节点库默认使用紧凑卡片。有分组的订阅默认展示分组。
- 修复 Windows 虚拟网卡服务启动问题，支持普通用户重启已安装的服务。Windows 构建默认使用官方签名更新渠道。
- Android 同步内置语言包并更新应用版本。

Windows 可在应用内更新或下载 x64 安装包。Android 可在应用内更新，也可下载与设备架构匹配的 APK 或通用 APK。

## Air Proxy 1.1.6

- The Windows dashboard shows the Google and GitHub logos alongside their HTTPS response times. Open the card's details to see all four checks, including YouTube and ChatGPT, or run them again.
- The Windows dashboard shows node health, plan quota, and live traffic routing, with shortcuts to the node library, subscriptions, and routing settings. Copy the local proxy address with one click while the proxy is running.
- The Windows node library defaults to compact cards. Subscriptions with groups show the groups first.
- Fixed Windows virtual network adapter service startup and enabled standard users to restart the installed service. Windows builds use the official signed update channel by default.
- Android includes the refreshed language packs and app version.

Update in the app or use the Windows x64 installer. Android users can also install the APK for their architecture or the universal APK.
