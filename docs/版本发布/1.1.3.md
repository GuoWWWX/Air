## Air Proxy 1.1.3

Air Proxy 1.1.3 重点解决双栈网络下的 IPv6 旁路漏流与高画质视频卡顿问题，并为 Android 与 Windows 带来真正的应用内增量更新体验。

### 主要更新

- **跨端网络速度与视频流畅度大幅提升**：
  - **TUN 全量接管 IPv6 防旁路漏流**：升级 Windows 内置 Mihomo 内核至 `v1.19.32-air.3`（合入 `Air-TUN` 接管地址与禁 IPv6 前置拦截补丁），并同步调整 Android `VpnService`（含 `64:ff9b:1::/48` 本地 NAT64 前缀）；即使关闭“允许 IPv6”，双栈网络下的 IPv6 流量也不会再绕过 TUN 走慢速直连。
  - **默认 Fake-IP 与海外 QUIC 回落**：双端默认启用 `fake-ip`（内置 `geosite:cn` 过滤）与海外 QUIC（UDP 443）拦截，强制海外 HTTPS/视频流回落更稳定的 TCP/TLS，不影响国内直连、游戏与语音；未修改过出厂默认网络配置的旧版本升级后自动迁移。
  - **Sniffer 域名嗅探覆盖**：开启 `parse-pure-ip` 与 `override-destination`（保留 HTTP 明文安全例外），改善自带 DoH 应用的分流准确度与 CDN 节点调度。
- **Android 应用内块级增量更新与自动安装**：
  - 支持直接复用本地已安装 APK 中未变更的 ZIP 条目，仅通过 4 路并发 Range 下载增量部分并实时展示进度条、复用字节与速率。
  - 新增「暂停 / 继续下载 / 取消 / 忽略此版本」控制、底栏单行操作布局、`SHA-256` 校验失败自动回落全量包、右上角隐蔽 GitHub 兜底图标，以及下载完成后的 `FileProvider` 自动拉起覆盖安装。
- **Windows 二进制瘦身与 `AIRDLT1` 增量补丁**：
  - 开启桌面发行版大小与 LTO 优化（`opt-level = "s"` / `lto = "thin"` / `strip = true`），并支持从 `v1.1.1` / `v1.1.2` 直接拉取 `AIRDLT1` 块差分补丁，保持 `schema: 1` 与分块回落完全兼容。
- **移动端节点卡片高度稳定**：移除节点库卡片内的选中图钉图标及额外右内边距，切换当前节点时卡片不再触发换行或高度跳变。

### 安装与核对

- **Windows（`x86_64`，Windows 10/11）**：下载 `Air-Proxy-1.1.3-windows-x64-setup.exe` 安装或覆盖升级；已安装用户也可在软件内通过增量补丁与签名清单直接升级（含 Ed25519 校验与断点续传）。
- **Android**：按设备架构选择 `Air-Proxy-1.1.3-android-arm64-v8a.apk`（主流手机）、`armeabi-v7a`、`x86_64` 或通用包 `Air-Proxy-1.1.3-android-universal.apk` 覆盖安装；已安装用户可在应用内直接增量更新。
- **校验与开源许可**：所有分发文件均可通过本页 `SHA256SUMS.txt` 核对 SHA-256 校验和；第三方组件许可与源码信息见同页 `THIRD-PARTY-NOTICES.md`。[Mihomo 源码](https://github.com/MetaCubeX/mihomo/tree/88dcbf7f1614a67c3b36b848ee3592dfa92ada36) · [GPL-3.0 许可证](https://github.com/MetaCubeX/mihomo/blob/v1.19.32/LICENSE)

## Air Proxy 1.1.3

Air Proxy 1.1.3 eliminates dual-stack IPv6 bypass leaks and overseas streaming stalls while delivering true in-app incremental updates on both Android and Windows.

### Highlights

- **Cross-Platform Throughput & Video Streaming Fixes**:
  - **Full IPv6 Anti-Leak Capture in TUN**: Upgraded Windows Mihomo to `v1.19.32-air.3` (retaining `Air-TUN` IPv6 capture addresses and blocking disabled IPv6 traffic before sniffing/ICMP forwarding) and updated Android `VpnService` (including `64:ff9b:1::/48` NAT64 routing), preventing dual-stack IPv6 traffic from leaking past the tunnel when outbound IPv6 is disabled.
  - **Default Fake-IP & Overseas QUIC Fallback**: Switched default `enhancedMode` to `fake-ip` (with `geosite:cn` bypass) and enabled overseas QUIC (`UDP 443`) blocking by default so international HTTPS/video flows fall back to stable TCP/TLS without affecting domestic traffic, gaming, or voice; untouched factory network configs migrate automatically.
  - **Sniffer Pure-IP Domain Override**: Enabled `parse-pure-ip` and `override-destination` (preserving the HTTP plaintext exception) for more accurate domain routing and CDN selection.
- **Android In-App Incremental Updater & Auto Install**:
  - Reuses unchanged ZIP entries from the installed APK and fetches remaining bytes across 4 concurrent HTTP Range workers with live progress, speed, and reused-bytes badge.
  - Adds **Pause / Resume / Cancel / Ignore**, a unified single-row sheet footer, SHA-256 verification with automatic full-APK fallback, a subtle GitHub fallback icon, and automatic overwrite installation via `FileProvider`.
- **Windows Binary Size Optimization & `AIRDLT1` Binary Delta Patches**:
  - Enabled release size/LTO optimization (`opt-level = "s"`, `lto = "thin"`, `strip = true`) and shift-invariant `AIRDLT1` binary delta patches from `v1.1.1` / `v1.1.2` with seamless `.pack` fallback.
- **Mobile Node Card Layout Stability**: Removed the selected pin icon and extra heading padding from Node Library cards so selecting nodes never wraps titles or alters card height.

### Install & Verify

- **Windows (`x86_64`, Windows 10/11)**: Run `Air-Proxy-1.1.3-windows-x64-setup.exe` for fresh install or overwrite upgrade, or update in-app via Settings → About (Ed25519-verified delta/chunk updates).
- **Android**: Install `Air-Proxy-1.1.3-android-arm64-v8a.apk` (most phones), `armeabi-v7a`, `x86_64`, or `Air-Proxy-1.1.3-android-universal.apk`, or update directly inside the app.
- **Checksums & Licenses**: Verify all assets with `SHA256SUMS.txt` and review open-source notices in `THIRD-PARTY-NOTICES.md`.
