## Air Proxy 1.1.7

- Windows 首页新增服务连通性卡片，默认显示 Google 和 GitHub 的 HTTPS 响应耗时。展开后可查看 YouTube、ChatGPT、Wikipedia、Cloudflare 和 Bing，也可重新检测。点击站点名称或图标会用默认浏览器打开。
- 启动代理或切换节点后，线路连续稳定 3 秒才自动检测。快速切换时只检测最终选中的线路。手动重测立即开始，等待时间不计入显示的耗时。
- Windows 首页增加节点健康、套餐余量和实时分流概览，可直达节点库、订阅和分流设置。代理运行时可一键复制本地代理地址。节点库默认使用紧凑卡片，有分组的订阅默认展示分组。
- 修复 Windows 虚拟网卡服务的启动问题，支持普通用户启动已安装的服务。Windows 构建默认使用官方签名更新渠道。
- Android 同步内置语言包并更新应用版本。

Windows 可在应用内更新或下载 x64 安装包。此安装包尚无 Authenticode 签名，从浏览器下载后可能出现 SmartScreen 提示。Android 可在应用内更新，也可下载与设备架构匹配的 APK 或通用 APK。

## Air Proxy 1.1.7

- The Windows dashboard shows HTTPS response times for Google and GitHub. Open the card to see YouTube, ChatGPT, Wikipedia, Cloudflare, and Bing, or run the checks again. Select a site name or icon to open it in your default browser.
- Automatic checks run once the route has been stable for three seconds after starting the proxy or switching nodes. Rapid switches are checked once on the final route. Manual checks start immediately. Displayed timings measure the requests themselves.
- The Windows dashboard shows node health, plan quota, and live routing, with shortcuts to the relevant pages. Copy the local proxy address while the proxy is running. The node library defaults to compact cards, and subscriptions with groups show the groups first.
- Fixed Windows virtual network adapter service startup and enabled standard users to start the installed service. Windows builds use the official signed update channel by default.
- Android includes the refreshed language packs and app version.

Update in the app or use the Windows x64 installer. The installer may trigger SmartScreen when downloaded in a browser because it has no Authenticode signature. Android users can also install the APK for their architecture or the universal APK.
