## Air Proxy 1.1.4

Air Proxy 1.1.4 是针对 Windows 双栈网络 `v1.1.3` 断网问题的紧急热修复版本，完整保留 `v1.1.3` 的全部网络优化与应用内增量更新能力。

### 主要修复

- **修复关闭 IPv6 时双栈污染 AAAA 导致的断网问题**：
  - 在国内双栈宽带环境下，物理网卡上的路由器 IPv6 DNS（如 `fe80::1`）可能通过系统多网卡并行解析向应用返回被污染的 AAAA 记录（如 `2001::1`），`Air-TUN` 捕获该 IPv6 连接并在本地完成 TCP 握手后，`v1.19.32-air.3` 在域名嗅探之前就丢弃了 IPv6 目标连接，导致 YouTube 等海外网站无法回落 IPv4、页面提示“未连接到互联网”。
  - 本版本将 Windows 内置 Mihomo 内核升级至 `v1.19.32-air.4`：将 `DisableIPv6` 检查后移到 **TLS/HTTP/QUIC 域名嗅探之后**；当嗅探到真实域名时清除被污染的 IPv6 目标地址、正常改走域名代理或 IPv4 直连，同时继续拦截没有域名的纯 IPv6 字面量与 ICMPv6。
- **继承 `1.1.3` 全部特性**：包含 Android 应用内块级增量更新、Windows `AIRDLT1` 二进制差分补丁、默认 `fake-ip`（含 `geosite:cn`）、海外 QUIC（UDP 443）拦截及移动端节点卡片布局稳定修复。

### 安装与核对

- **Windows（`x86_64`，Windows 10/11）**：下载 `Air-Proxy-1.1.4-windows-x64-setup.exe` 安装或覆盖升级；`1.1.2` / `1.1.3` 用户也可在软件内直接增量更新。升级后若弹出 Windows 管理员授权提示，请点击同意以将 `AirTunService` 同步更新至 `v1.19.32-air.4`。
- **Android**：按设备架构选择 `Air-Proxy-1.1.4-android-arm64-v8a.apk`（主流手机）、`armeabi-v7a`、`x86_64` 或通用包 `Air-Proxy-1.1.4-android-universal.apk` 覆盖安装，或在应用内直接增量更新。
- **校验与开源许可**：所有分发文件均可通过本页 `SHA256SUMS.txt` 核对 SHA-256 校验和；第三方组件许可与源码信息见同页 `THIRD-PARTY-NOTICES.md`。[Mihomo 源码](https://github.com/MetaCubeX/mihomo/tree/88dcbf7f1614a67c3b36b848ee3592dfa92ada36) · [GPL-3.0 许可证](https://github.com/MetaCubeX/mihomo/blob/v1.19.32/LICENSE)

## Air Proxy 1.1.4

Air Proxy 1.1.4 is a hotfix release resolving Windows dual-stack outage in `v1.1.3`, while keeping all throughput optimizations and in-app incremental updates.

### Key Fixes

- **Fix Dual-Stack Poisoned AAAA Outage When IPv6 Is Disabled**:
  - On Windows dual-stack networks, an upstream physical router IPv6 DNS (e.g. `fe80::1`) can inject poisoned AAAA records (such as `2001::1`) via Smart Multi-Homed Name Resolution. Once `Air-TUN` accepted the TCP handshake locally, `v1.19.32-air.3` dropped the IPv6 destination *before* TLS/HTTP/QUIC domain sniffing, preventing fallback and breaking sites like YouTube.
  - Upgraded the bundled Windows Mihomo core to `v1.19.32-air.4`, moving the `DisableIPv6` check *after* sniffing: sniffed domains clear the poisoned IPv6 destination and proceed normally over proxy or IPv4, while domainless IPv6 literals and ICMPv6 remain blocked.
- **Includes All `1.1.3` Improvements**: Android in-app ZIP-entry incremental updater, Windows `AIRDLT1` binary delta patches, default `fake-ip` with `geosite:cn`, overseas QUIC (`UDP 443`) fallback, and stable mobile node card height.

### Install & Verify

- **Windows (`x86_64`, Windows 10/11)**: Run `Air-Proxy-1.1.4-windows-x64-setup.exe` or update in-app from `1.1.2` / `1.1.3`, and accept the UAC prompt on reconnect to upgrade `AirTunService` to `v1.19.32-air.4`.
- **Android**: Install `Air-Proxy-1.1.4-android-arm64-v8a.apk` (most phones), `armeabi-v7a`, `x86_64`, or `Air-Proxy-1.1.4-android-universal.apk`, or update in-app.
