## Air Proxy 1.1.1

Air Proxy 1.1.1 重点优化 Windows 安装向导、虚拟网卡系统标识以及国内宽带开箱网络体验，并保持 Android 端与桌面端能力同步。

### 主要更新

- **Windows 覆盖安装体验优化**：已在电脑上安装 Air Proxy 后再次运行安装包时，向导直接展示「覆盖安装」并保留现有配置、订阅与本地数据，不再默认提示先卸载旧版。
- **虚拟网卡系统标识更清晰**：将 Windows 虚拟网卡驱动类型描述由 `sing-tun` 改为 **`Air Tun`**（系统显示 `Air Tun Tunnel`），并将虚拟网卡服务协议版本升级至 `v12`，避免与第三方内核混淆，同时兼容旧版已安装服务平滑迁移。
- **国内宽带默认网络优化**：
  - Windows 桌面端默认关闭 IPv6 与 AAAA 解析（与 Android 端保持一致），避免原生 IPv6 网络环境下直连或代理握手回退造成数秒延迟，需要时可在「设置 → 代理接入」手动开启。
  - Windows 桌面端默认 TUN 协议栈调整为 **`mixed`**（系统 TCP + gVisor UDP），提升高并发与网页/下载吞吐稳定性。
  - 将国内直连 DNS（`geosite:cn,private` 优先走阿里/腾讯 DNS）的兜底策略覆盖至所有开启「DNS 连接遵循分流规则」的场景，即使修改了主 DNS 或从订阅导入解析列表也不会意外失效；同步对齐 Android 端策略：关闭「DNS 连接遵循分流规则」时不再自动注入国内直连 DNS 覆写，单选上游测试解析时自动绕过分流规则直测目标上游。
  - 升级时若未手动修改过网络配置，桌面端自动迁移至上述优化默认值；已自定义的用户配置完整保留。

### 安装与核对

- **Windows（`x86_64`，Windows 10/11）**：下载 `Air-Proxy-1.1.1-windows-x64-setup.exe` 安装或覆盖升级；已安装用户也可在「设置 → 关于」内点击「检查更新」通过 Ed25519 签名校验与断点续传升级。
- **Android**：按设备架构选择 `Air-Proxy-Android-1.1.1-arm64-v8a.apk`（主流手机）、`armeabi-v7a`、`x86_64` 或通用包 `universal.apk` 覆盖安装。
