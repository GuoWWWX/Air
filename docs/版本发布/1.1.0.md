## Air Proxy 1.1.0

Air Proxy 1.1.0 统一 Windows 桌面版与 Android 手机版的品牌命名与交互细节，增强双端更新推送，并修复网络接管与测速路由的关键问题。

### 主要更新

- **品牌与界面统一**：全面统一应用与提示名称为 **Air Proxy**；桌面仪表盘调整运行按钮外圈柔和脉冲光环与分段渐隐过渡，侧栏仅在缺少内核时提示「诊断内核」，右侧策略分组支持完整列表滚动与精准高亮跳转，订阅内容区合并为全高列表视图。
- **更新推送与本地代理兜底**：Windows 增量更新在直连更新源受阻时自动回落至当前活跃的本地代理端口完成检查与分块续传；Android 端支持启动静默检查（6 小时节流）、底栏红蓝点与版本号徽标提示、优先匹配设备 ABI 的 APK 直链下载及更新说明展示。
- **稳定性与安全修复**：
  - 修复 Android 8–12L 同时开启 IPv6 与「绕过局域网私网」时遗漏 `64:ff9b::/96` NAT64 前缀导致部分流量绕过 VPN 的问题。
  - 修复 Windows 修改代理端口并更新系统代理失败后，已切换的新内核端口与回滚配置文件不一致的问题。
  - 修复 Android 自动分组使用已过期超过 24 小时测速记录的问题，支持定时与返回前台即时重算。
- **文档与发布规范**：补充 Windows `air-tun-service.exe` 打包前置脚本说明及离线冷启动验证命令。

### 安装与核对

- **Windows（`x86_64`，Windows 10/11）**：首次安装请下载 `Air-Proxy-1.1.0-windows-x64-setup.exe`；已安装 `1.0.0` 的用户可在「设置 → 关于」内点击「检查更新」，通过 Ed25519 签名验证与断点续传升级。
- **Android**：按设备架构选择 `Air-Proxy-Android-1.1.0-arm64-v8a.apk`（主流手机）、`armeabi-v7a`、`x86_64` 或通用包 `universal.apk` 覆盖安装。
- **校验与开源许可**：所有安装包均可通过本页 `SHA256SUMS.txt` 校验摘要。Windows 随附 Mihomo `v1.19.32`（`x86-64-v2`）与 Wintun，Android 集成 `libmihomo-android v0.3.14`；完整第三方许可与对应源码地址见同页 `THIRD-PARTY-NOTICES.md`。[Mihomo 源码](https://github.com/MetaCubeX/mihomo/tree/88dcbf7f1614a67c3b36b848ee3592dfa92ada36) · [GPL-3.0 许可证](https://github.com/MetaCubeX/mihomo/blob/v1.19.32/LICENSE)
