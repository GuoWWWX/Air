## Air Proxy 1.1.2

Air Proxy 1.1.2 重点升级更新推送下载性能、断点暂停/取消控制、双端新版本视觉提醒与多语言更新说明支持。

### 主要更新

- **更新下载大幅提速**：
  - Windows 与 Android 在代理运行时优先复用本地代理端口请求更新源与安装包，并保留直连兜底；国内宽带直连受限环境下也能稳定高速拉取更新。
  - Windows 更新器启用连接池复用与 **4 路并发分块下载**（按分块断点续传与异步校验），显著缩短等待时间。
- **更新支持暂停与取消**：Windows 端在下载与准备阶段新增「**暂停** / **继续下载**」与「**取消**」按钮；暂停后保留已校验分块缓存且不触发后台静默续传，取消则清理临时缓存并恢复可更新状态。
- **高辨识度脉冲提醒与紧凑弹窗**：
  - 桌面端左下角侧栏与 Android「设置 / 关于」入口升级为带橙色脉冲呼吸灯的强调样式，有新版本时一目了然。
  - 收窄收矮桌面端更新弹窗并缩小更新说明字号；Android「关于」页同步升级为紧凑 Markdown 排版。
- **多语言更新说明与定期自动检测**：更新日志支持根据当前界面语言自动切换中文 / 英文内容；Windows 维持启动检查与每 6 小时后台自动检测，Android 新增「切回前台超过 6 小时自动静默检测」。

### 安装与核对

- **Windows（`x86_64`，Windows 10/11）**：下载 `Air-Proxy-1.1.2-windows-x64-setup.exe` 安装或覆盖升级；已安装用户也可在「设置 → 关于」或左下角提醒处直接在线升级（支持 Ed25519 签名校验与 4 路并发断点续传）。
- **Android**：按设备架构选择 `Air-Proxy-1.1.2-android-arm64-v8a.apk`（主流手机）、`armeabi-v7a`、`x86_64` 或通用包 `Air-Proxy-1.1.2-android-universal.apk` 覆盖安装。
- **校验与开源许可**：所有分发文件均可通过本页 `SHA256SUMS.txt` 核对 SHA-256 校验和；第三方组件许可与源码信息见同页 `THIRD-PARTY-NOTICES.md`。[Mihomo 源码](https://github.com/MetaCubeX/mihomo/tree/88dcbf7f1614a67c3b36b848ee3592dfa92ada36) · [GPL-3.0 许可证](https://github.com/MetaCubeX/mihomo/blob/v1.19.32/LICENSE)

## Air Proxy 1.1.2

Air Proxy 1.1.2 upgrades updater download speed, pause/resume/cancel controls, cross-platform update indicators, and localized release notes.

### Highlights

- **Faster Proxy-First & Concurrent Downloads**:
  - Both Windows and Android prefer the active local proxy port when checking or fetching updates (with automatic direct fallback), keeping update downloads fast even when direct GitHub CDN access is throttled.
  - The Windows updater reuses pooled HTTP connections and downloads update chunks across **4 concurrent workers** with per-chunk resume and async SHA-256 verification.
- **Pause, Resume & Cancel Support**: The Windows update dialog now provides **Pause / Resume** (retaining verified chunk caches without auto-resuming in the background) and **Cancel** (clearing temporary update state and resetting back to available).
- **Clearer Update Badges & Compact Dialogs**:
  - Desktop bottom-left sidebar and Android Settings / About entries now display an accented glowing pulse dot whenever a new version is ready.
  - Desktop update dialog uses a tighter width/height with crisp compact Markdown typography, and the Android About screen now renders Markdown release notes directly.
- **Localized Release Notes & Automatic Checks**: Release notes automatically switch between Chinese and English to match your UI language; Desktop checks on launch and every 6 hours in the background, and Android now also triggers a silent 6-hour-throttled check when returning to the foreground.

### Install & Verify

- **Windows (`x86_64`, Windows 10/11)**: Run `Air-Proxy-1.1.2-windows-x64-setup.exe` for fresh install or overwrite upgrade, or update in-app via Settings → About (Ed25519-verified with 4-way resumable chunks).
- **Android**: Install `Air-Proxy-1.1.2-android-arm64-v8a.apk` (most phones), `armeabi-v7a`, `x86_64`, or `Air-Proxy-1.1.2-android-universal.apk`.
- **Checksums & Licenses**: Verify all assets with `SHA256SUMS.txt` and review open-source notices in `THIRD-PARTY-NOTICES.md`.
