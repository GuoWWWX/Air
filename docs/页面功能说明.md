# Air Proxy 页面与功能使用说明

本说明面向仓库中的 **Windows 桌面版** 与 **Android 手机版**，全面介绍各页面布局、交互细节与双端差异。第一次使用时，打开「订阅 → 导入订阅」，预览并确认导入，再到「节点库」选择出口、测试延迟，回到「仪表盘」启动代理。

> 扩展文档：如需了解底层代码与模块如何实现，请参阅 [功能实现文档目录](./功能实现/README.md)；如需查看分流规则库与多级绑定的演进规划，请参阅 [功能需求文档目录](./功能需求/README.md)。

### 全局交互、窗口托盘与系统提示

- **全局消息提示胶囊**：双端统一顶部胶囊通知。默认收敛为紧凑单行文本（不自动换行撑大页面），包含副标题描述或标题被截断的提示会显示展开角标，**点击可展开查看完整详情**并暂停倒计时；无论电脑鼠标还是手机手指，均支持**向上、向左、向右拖动关闭**（向下拉动回弹不误关闭）。
- **Windows 系统控制**：点击托盘图标可打开主窗口；托盘菜单支持直接启动/停止代理、切换规则/全局/直连、开关系统代理和虚拟网卡。收起侧栏可扩大连接日志与节点库宽度；关闭窗口默认收进托盘，从托盘退出才结束程序。
- **Android 原生体验**：首次启动代理时向系统申请 VPN 授权，连接期间由前台服务维持隧道并在通知栏实时汇报速率。Android 端已从原生 `WebView`、视口与手势事件层全面禁用双指放大缩小及浏览器自带右键/拖拽行为，同时保留长按卡片管理及文本编辑区内的复制粘贴；按系统返回键优先关闭菜单、抽屉或设置子页。

## 仪表盘与启动

| 操作 | Windows | Android |
| --- | --- | --- |
| 选择接管方式 | 系统代理与虚拟网卡（TUN）独立控制。开启 TUN 时，缺少 Air 服务可从应用内安装并请求一次管理员授权，之后日常切换免弹窗。开启 TUN 期间自动维护局域网设备发现（mDNS/SSDP/LLMNR）临时路由。 | 通过 Android `VpnService` 统一建立 VPN 虚拟网卡隧道（含 DNS 53 端口接管、按应用分应用与 Android 13+ 绕过网段），并在设置页可选开启本地 HTTP/SOCKS 混合监听端口。 |
| 启停与切换模式 | 顶栏、仪表盘与托盘均可控制，实时响应呼吸电源按钮及动画平滑过渡。 | 点击首页动态波浪电源按钮或下滑后顶栏迷你电源按钮启停；通过平滑滑动块分段器切换「规则 / 全局 / 直连」出站模式（即时生效无灰态闪烁）。 |
| 查看与滚动交互 | 查看当前出口、节点延迟、内存占用、实时速率及完整实时连接表格（直接显示出口节点名，不再拼接冗余前缀）；点击表格任意连接即可修改该软件或域名的分流策略。 | 查看当前出口、VPN 状态、运行时长与上下行趋势图；实时连接卡片直接显示出口节点名称，在内部连接列表滑到顶部或底部边界后继续滑动可无缝带动整页上下滚动；点击连接卡片直接进入分流策略抽屉。 |
| 验证出口 | 启动后经当前代理探测公网出口 IP、国旗与运营商归属；切换出口自动重新检测，同一节点回到仪表盘自动复用缓存；亦可点击手动刷新。 | 从仪表盘或连接详情检测并刷新当前出口 IP 与归属信息，点击出口 IP 一键复制到剪贴板。 |

规则模式按规则顺序分流，全局模式使用所选代理出口，直连模式让连接直接发出。节点名称前的旗帜来自节点信息，出口验证反映实际探测到的公网地址。延迟测试记录连接测试目标所需的时间，视频吞吐量需要通过实际传输观察。

## 订阅

### 导入与浏览

可以粘贴订阅链接、打开 Clash YAML 文件、使用相机扫码或选取二维码图片。手机远程导入限制使用 HTTPS。预览显示可识别的节点和分组，确认后写入本机。来源卡片显示名称、节点/分组数量与流量用量/到期时间。

勾选一个或多个来源可汇总浏览节点与分组（不影响「当前选定出口」和自动跟随时所使用的分流规则）。桌面在右侧展示节点和分组，手机点「管理所选」进入列表。

### 名称、身份与刷新状态

| 场景 | 两端的行为 |
| --- | --- |
| URL 或二维码导入 | 优先使用手填名称；留空时读取最终下载响应的 `Profile-Title`（支持普通文本与 `base64:` 编码 UTF-8 标题）；缺失或无效时取 URL 主机名。 |
| 本地 YAML 导入 | 优先使用手填名称，留空时采用所选文件的名称（含扩展名）。 |
| 同名来源 | 不同链接返回同名标题时自动顺延显示为 `Family`、`Family (1)`、`Family (2)` 并独立保留节点、用量和更新状态；刷新保留已有编号。 |
| 同步后改名 | 未手动改名的来源在服务端修改标题时跟随更新；手动修改过的名称在同步与自动更新后均永久保留。 |
| 更新失败或订阅过期 | 刷新失败提示原因并继续保留上次可用配置；可随时手动重试或修改订阅链接。 |

### 每个订阅可以做什么

桌面点击来源右上角的「⋯」，手机点击来源卡片管理菜单或「管理所选」内顶栏操作：

| 操作 | 用法 |
| --- | --- |
| 编辑订阅 | 修改显示名称与远程链接。 |
| 编辑 YAML | 对照「生效配置 / 本地修改 / 订阅原文」多视图检查、语法校验并保存本地副本，可随时「恢复订阅原文」。 |
| 扩展 | 保存附加分流规则文本与 JavaScript 扩展脚本（沙箱隔离执行 `main(config)`，再将附加规则置于订阅规则前端）。 |
| 同步 / 自动更新 | 立即同步单个或全部远程来源；可单独开启/暂停自动更新与调整间隔（1~720 小时，默认读取 `profile-update-interval` 或 24 小时）。存在本地 YAML、扩展或节点覆写时自动暂停远程覆盖直至手工恢复。 |
| 更多 → 运行时配置 | 查看当前订阅实际下发到内核或预览生成后的完整 YAML 配置。 |
| 更多 → 复制链接、二维码 | 一键复制完整订阅 URL 或本机离线生成二维码供其他设备扫码导入。 |
| 更多 → 导出文件 | 导出经过本地编辑与扩展计算后的 YAML 配置文件。Windows 通过下载保存，Android 弹出系统文件选择器指定名称与目录。 |
| 更多 → 上移/下移 & 删除 | 独立调整订阅显示顺序；删除订阅时自动清理失效节点与分流引用（Android 若移除了唯一运行中的代理出口会安全停用 VPN）。 |

```javascript
function main(config) {
  const node = config.proxies.find(proxy => proxy.name === '东京')
  if (node) node.port = 8443
  return config
}
```

## 节点库、分组与链路

| 功能 | Windows | Android |
| --- | --- | --- |
| 查找与选择 | 左侧来源树 + 搜索框 + 卡片（三档密度）/表格视图 + 排序与分页，支持多选复制节点/加入分组，以及单独将某节点或链路设为当前出站。 | 顶部作用域选择器 + 搜索条 + 卡片（三档密度）/列表视图，点选节点即刻设为当前出口，进入「多选」模式支持批量测速与加入分组。 |
| 测速体验与队列 | 使用独立诊断内核测速（主代理停止亦可测），后台调度器高并发去重探测，支持单节点独立点测与批量测速中止。 | 支持**多节点连续点选排队并发测速**：点击任意空闲节点或已测完节点立即加入队列转圈（批量测速期间其它节点卡片也保持可点击），原生 `:diagnostics` 进程边测边将每个完成节点的延迟流式推回界面并**立刻解锁对应卡片**；批量测速总进度（`done/total`）以紧凑蓝色 `Tag` 显示在工具栏右侧，点击旋转图标随时中止。 |
| 自定义节点与覆写 | 可添加自定义 HTTP/HTTPS/SOCKS5 节点；订阅节点可编辑本地覆写名、地址、端口或恢复原文。 | 支持自定义节点表单与内置测试；订阅节点可保存本地覆写、恢复原文或本地隐藏。 |
| 分组 | 来源树支持订阅分组、嵌套式自定义分组及批量管理成员。在自定义分组上选择「设为自动出站」可以让该组按延迟选取出口。 | 支持浏览订阅分组、创建手动分组或按来源/延迟上限/节点数量自动筛选成员的自动分组，支持直接选分组作为出站。 |
| 链路 | 在侧边链路面板按顺序编排多跳节点、命名保存、加载、删除与整链测试。 | 支持创建/编辑多跳链路、调换各跳节点顺序、一键设为当前出口以及「测整链」全路径可达性测试。 |

单节点测速仅经过待测节点；整链测速按保存顺序经过各跳；两端测速与运行配置都会按节点所属订阅自动注入对应的顶层 `hosts` 作用域，避免同名域名解析混淆。

## 连接日志与精细分流策略

仪表盘展示实时连接概览，「连接日志」完整保留近期及当前活跃连接，支持关键词搜索、状态筛选（全部 / 已连通 / 异常）与诊断细节查看。

| 区域 | 两端说明与差异 |
| --- | --- |
| 应用与出口展示 | 系统能识别进程/包名时直接展示应用图标与可读名称，代理出站 `Tag` 直接显示实际出口节点名称（直连/拒绝按绿/红色区分）。Windows 区分下载量与上传量列，Android 卡片同时显示活跃/已结束/已拒绝状态、发生时间、路由汇总及双向上下行累积流量。 |
| 点击修改应用/域名分流策略 | 在实时连接或连接日志中点击任意连接记录（或桌面端/手机端详情内入口），均可直接为该连接所属**应用（Windows 支持进程名/路径，Android 10+ 支持应用包名）**或**特定域名 / 后缀 / IP** 设置直连、走代理、指定节点/分组/链路或拒绝；支持先只放行/代理该应用的某个特定域名，并自动将细分复合规则排在该应用整包规则之前。保存时支持立即断开旧连接使新策略秒级生效。 |
| 连接诊断 | 可查看命中的分流规则原文、完整出站链条路径（`chains`）及整链探测各跳耗时；Android 还支持直接断开单条指定活跃连接及清空已结束记录。 |

## 设置

| 设置项 | 可用操作与平台差异 |
| --- | --- |
| 启动（Windows） | 控制登录 Windows 时开机自启、启动 Air 时自动开启上次代理；关闭窗口收到托盘，从托盘退出程序。 |
| 外观（主题与语言） | 主题支持跟随系统、浅色和深色。「语言」设置整合在主题之后，默认收起语言包目录路径与「导入语言包」按钮，点击整行即可展开或收起，下拉切换内置中文/英文即时生效；导入的自定义 JSON 语言包重启后生效。[添加语言包](开发构建与清理.md#界面语言和自定义语言包) |
| 网络与 DNS | 管理主 DNS、引导 DNS、直连 DNS、节点解析 DNS、备用及分域 DNS，支持「从订阅读取 DNS」与一键解析测试，支持切换真实 IP / Fake-IP、IPv6 与 TCP 并发，并支持本地 `hosts` 规则。 |
| 虚拟网卡（TUN）与接入 | 调整协议栈（gVisor / Mixed / System）、MTU、DNS 接管（劫持 53 端口 DNS 查询由内核统一分流）、严格路由（Windows）、绕过网段（Android 13+）及混合代理端口（Windows 另设系统代理绕过清单，Android 留空可停用本地混合端口）。 |
| 局域网设备发现（Windows） | 开启 TUN 后，Air 为 mDNS、SSDP 和 LLMNR 多播地址维护物理网卡临时路由，切换网络更新、关闭 TUN 移除。 |
| 分流规则 | 查看当前出站生效的规则集、预览有序规则、设置未命中的默认出口。软件规则按应用聚合，独立域名/IP 规则各占一行。 |
| 分流规则库 | 在「分流规则」中打开。可以查看订阅自带规则、克隆模板、新建或导入自建规则集，查看绑定对象，编辑、导出或删除自建规则集。 |
| 诊断内核与配置 | Windows 可检测随包 Mihomo 或自定义内核路径；Android 可查看内置内核版本/ABI 并校验当前编译方案。两端均可编辑、校验与导入/导出 YAML 配置文件（Windows 支持外部编辑冲突检测与 `air-config.previous.yaml` 自动备份）。[目录与备份](开发构建与清理.md#本机配置目录) |
| 后台监测 | Windows 收起窗口后后台低并发定时刷新节点延迟；Android 开启后由系统定时调度（>=15 分钟）并在回到应用后合并结果。 |
| 关于与软件更新 | 查看当前版本、许可证与作者主页；Windows 支持应用内检查并下载安装新版本更新包及查看更新说明，Android 支持版本检查并跳转下载。 |

> 交互提示：在桌面端和手机端「设置」主页滚动浏览并点击进入任意子设置页后返回，页面会自动恢复之前停留的滚动位置。

### 查看从连接日志修改的出站

打开「设置 → 分流规则 → 自定义规则」。例如在实时连接里把整个小红书设为直连后，找到「小红书」（包名 `com.xingin.xhs`）这一行即可查看默认出站和例外数量。点开这行，在手机底部面板或桌面弹窗中编辑、排序、停用或删除例外。单独为全设备设置的域名或 IP 会显示为独立一行。这些修改保存在全局规则里，切换节点后仍然生效。

### 当前节点使用哪套规则

通常保持「跟随默认」即可。订阅节点自动跟随所属订阅，先匹配用户设置的全局规则。需要例外时，打开订阅编辑、自定义分组编辑、节点详情或覆写、自定义节点或链路编辑，调整「分流规则」选项。也可进入「分流规则库 → 管理绑定」集中修改。删除自建规则集后，其绑定对象恢复「跟随默认」。

从具体自定义分组中选择节点时，优先使用节点自身绑定，其次是本次分组绑定，再次是所属订阅。直接从「全部节点」选择时跟随节点和订阅。跨多个订阅的自动分组、自建节点和新建链路在没有绑定时使用国内直连兜底。原有多跳链路继续跟随末跳订阅，可在链路编辑中覆盖。选择「不使用规则集」时，国内直连兜底和全局规则仍然生效。

### Windows 配置示例

网络和测速参数写在 `network` 段，分流写在 `routing` 段。表单保存前会将上一次的完整原文写入同目录的 `air-config.previous.yaml`（保留手写注释）：

```yaml
network:
  nameserver:
    - https://223.5.5.5/dns-query
    - https://doh.pub/dns-query
  probeIntervalMinutes: 15
routing:
  matchFallback: { kind: direct }
  rules:
    - matcher: domainSuffix
      value: corp.example.com
      target: { kind: direct }
    - matcher: processPath
      value: 'C:\Program Files\Google\Chrome\Application\chrome.exe'
      target: { kind: residential }
```

| --- | --- |
| 仪表盘 | 选择节点并启动，核对出站模式无闪烁切换、出口 IP 缓存复用与实时连接出口展示；在手机端验证连接列表触边后继续滑动能无缝接管页面滚动。 |

| 连接日志 | 发起已知目标的请求，核对应用图标、实际出口节点名、规则命中路径及点击改写「应用 / 域名」策略即时断连生效。 |
| 设置 | 验证滚动位置记忆、外观折叠语言包、TUN 开关、网络保存重启持久化及桌面/手机配置文件编辑器。 |
