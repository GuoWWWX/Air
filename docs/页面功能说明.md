# Air 功能与使用说明

本说明适用于仓库中的 Windows 桌面版和 Android 手机版。第一次使用时，打开「订阅 → 导入订阅」，预览并确认导入，再到「节点库」选择出口、测试延迟，回到「仪表盘」启动代理。

## 页面和操作入口

| 页面 | Windows 入口与区域 | Android 入口与区域 |
| --- | --- | --- |
| 仪表盘 | 左侧主导航。顶栏显示当前出口、延迟、模式和接管开关。主区展示节点、上传下载、模式、服务、实时连接和分组。 | 底部主导航。当前出口、动态启停按钮、出站模式、流量、实时连接摘要与订阅入口。 |
| 订阅 | 来源列表可多选。右侧「订阅内容」按勾选范围展示分组和节点。每个来源有独立菜单。 | 来源卡片提供勾选、单独刷新和管理菜单。底部「管理所选」打开内容页，可再进入节点或分组操作。 |
| 节点库 | 来源与分组树、节点卡片或列表、节点详情和链路面板。勾选用于批量操作，设置当前出口有单独的按钮。 | 搜索、来源筛选、节点视图、分组与链路编辑。选为出口、多选加入分组、打开详情和测速分别操作。 |
| 连接日志 | 连接及探测表格、状态筛选和诊断详情。选中连接可查看内核报告的出站路径。 | 搜索与状态筛选、连接卡片、整链探测结果、选中连接的规则与出口详情。 |
| 设置 | 启动选项、主题、网络接管、分流、诊断、后台监测、配置文件与更新。 | 主题、网络与分流、内核、后台监测、配置文件及关于页面。返回可退出子页、菜单或弹窗。 |

### 窗口、托盘与系统通知

Windows 点击托盘图标可打开主窗口。托盘菜单提供启动或停止代理、规则／全局／直连、系统代理、虚拟网卡和退出。收起侧栏可以为表格留出空间。Android 第一次启动代理时会请求系统 VPN 授权，连接期间可从系统通知查看状态。

## 仪表盘与启动

| 操作 | Windows | Android |
| --- | --- | --- |
| 选择接管方式 | 系统代理接管遵循系统代理设置的应用。虚拟网卡（TUN）接管经过它的网络流量。缺少 Air 服务时，点击安装图标并确认，Windows 会要求一次管理员授权。 | 第一次启动时确认系统 VPN 授权。连接期间由 VPN 前台服务维持隧道，可从系统通知查看状态。 |
| 启停与切换模式 | 顶栏、仪表盘和托盘都提供代理控制。可分别切换系统代理、虚拟网卡和出站模式。 | 从仪表盘启动或停止 VPN，选择出站模式，节点库可切换当前出口。 |
| 查看运行状况 | 查看当前节点或链路、订阅来源、内核状态、代理地址、内存、实时连接、上传下载速率、峰值及累计流量。 | 查看所选出口、VPN 状态、运行时长、上下行速率与流量，以及订阅和实时连接入口。 |
| 验证出口 | 启动后检测出站 IP。结果可包含国旗、归属地、网络类型或风险标记，取决于查询返回的信息。 | 从仪表盘或连接诊断验证当前出口，查看可获取的 IP 和归属信息。 |

规则模式按规则顺序分流，全局模式使用所选代理出口，直连模式让连接直接发出。节点名称前的旗帜来自节点信息，出口验证反映实际探测到的公网地址。延迟测试记录连接测试目标所需的时间，视频吞吐量需要通过实际传输观察。

## 订阅

### 导入与浏览

可以粘贴订阅链接、打开 Clash YAML 文件、使用相机扫码或选取二维码图片。手机远程导入使用 HTTPS。预览显示可识别的节点和分组，点确认后写入本机。来源卡片显示名称和节点、分组数量。服务商提供用量和到期信息时，可查看已用流量、总量与到期时间。

勾选一个或多个来源可汇总浏览内容。桌面在右侧展示节点和分组，手机点「管理所选」进入列表。勾选来源只改变浏览范围，选择代理出口在节点库完成。

### 名称、身份与刷新状态

| 场景 | 两端的行为 |
| --- | --- |
| URL 或二维码导入 | 优先使用手填名称。留空时读取最终下载响应的 `Profile-Title`，支持普通文本和 `base64:` 编码的 UTF-8 标题。标题缺失、无效时取 URL 的主机名。 |
| 本地 YAML 导入 | 优先使用手填名称，留空时采用所选文件的名称（含扩展名）。YAML 内节点和分组的 `name` 只用于对应节点和分组。 |
| 同名来源 | 不同链接返回同名标题时依次显示为 `Family`、`Family (1)`、`Family (2)`，分别保留节点、用量和更新状态。刷新保留已分配的编号；同名文件分别导入也各有一条记录。同一链接重复导入沿用已有记录。编辑链接保留来源身份；重新导入已换掉的旧地址会创建独立来源。 |
| 同步后改名 | 自动命名的来源在服务商改标题时跟随更新。一次刷新未返回有效标题时保留已有名称。手动改过的名字在手动同步和自动更新时都保留。 |
| 旧版本升级 | 旧记录缺少名称来源标记。名称与原 URL 主机名完全相同时按旧默认名处理，在下次成功刷新并收到有效标题时纠正。其他旧名称保留。 |
| 更新失败或订阅过期 | 刷新失败显示错误，保留上次成功的内容。过期和用量来自服务商返回的数据。可手动重试，或编辑链接后重新下载。 |

### 每个订阅可以做什么

桌面点击来源右上角的「⋯」，手机点击来源卡片的管理按钮。

| 操作 | 用法 |
| --- | --- |
| 编辑订阅 | 修改显示名称和远程链接。修改名称便于区分同名来源。 |
| 编辑 YAML | 对照订阅原文、本地副本和生效配置。保存本地副本前会校验。要采用最近下载的原文，在编辑器里恢复订阅原文。 |
| 扩展 | 为这个来源保存附加分流规则、JavaScript 脚本，或同时使用两者。保存时会尝试将改动应用到正在使用的订阅。下载内容仍可在「订阅原文」查看。 |
| 同步 | 立即下载单个远程来源。「刷新全部」更新各远程来源。可在自动更新暂停时手动同步。失败原因显示在来源或操作提示中。 |
| 自动更新 | 单独为这个来源启用、暂停或更改间隔。适用于有订阅链接的来源。 |
| 更多 → 运行时配置 | 订阅参与当前代理会话时可以查看内核使用的配置。未使用的来源显示按当前设置生成的预览，首行注明是哪一种。 |
| 更多 → 复制链接、二维码 | 在订阅链接输入框旁或来源菜单复制完整链接。写入剪贴板成功后，按钮显示「复制成功」，一秒后恢复。也可显示供另一台设备扫描的二维码。二维码在本机生成，扫码者可以取得完整订阅链接。 |
| 更多 → 导出文件 | 导出该来源的 YAML，包括已保存的本地 YAML 和扩展结果。Windows 通过下载保存，Android 弹出系统文件选择器，可指定名称与目录。节点库里单独保存的节点覆写属于 Air 的节点设置。 |
| 更多 → 上移订阅、下移订阅 | 有多个来源时可调整列表顺序，退出后保留。排序独立于当前出口和分流优先级。 |
| 删除订阅 | 确认后移除来源和它的节点、订阅分组。Air 会处理失效的全局分流引用。Android 在删除最后一个正在使用的代理出口时会提示停止 VPN。 |

### 自动更新和本地修改

- **默认间隔**取服务商响应头 `profile-update-interval` 的有效小时数，未提供时为 24 小时。「自动更新」里可以填 1 到 720 小时，清空后重新跟随服务商。
- **本地修改**按来源管理。保存订阅 YAML、修改来源节点或保存扩展，会暂停该来源的自动更新。可在「自动更新」里自行恢复。已有订阅升级后，Air 会识别已有本地 YAML 或节点修改并保留。
- **手动同步和恢复自动更新**都会更新订阅原文和服务商返回的用量。本地 YAML 副本继续优先使用。只有恢复订阅原文，才会随下一份下载内容切换。节点覆写继续按节点标识匹配。扩展对所用的本地 YAML 或最新原文重新计算。下载、解析或执行扩展失败时保留上一份可用配置。
- **何时执行**由平台决定。Windows 在 Air 进程运行期间检查到期订阅，窗口收进托盘后也会检查。Android 在打开应用或回到前台时检查，系统也可以在后台有网络时预下载，回到应用后再校验和采用结果。省电限制可能推迟后台任务。纯本地文件可以编辑、扩展和导出。

扩展脚本入口为 `main(config)`，返回修改后的配置对象。例如把某个节点的端口改为服务商提供的新端口。

```javascript
function main(config) {
  const node = config.proxies.find(proxy => proxy.name === '东京')
  if (node) node.port = 8443
  return config
}
```

附加规则每行一条，例如 `DOMAIN-SUFFIX,example.com,DIRECT`。Air 先运行脚本，再把附加规则放到订阅规则前面。要让这份订阅参与规则分流，在「设置 → 分流规则」里选择它并开启规则继承。脚本在隔离环境中运行，有执行时间和内存限制。Air 管理的端口、DNS 和 TUN 等参数仍由软件设置生成。

## 节点库、分组与链路

| 功能 | Windows | Android |
| --- | --- | --- |
| 查找与选择 | 可搜索、按来源和分组浏览、切换卡片或列表、排序和分页，可多选、复制节点或地址、加入自定义分组、设置当前出口。 | 可搜索、按来源筛选、切换卡片或列表，点节点设置当前出口，多选节点加入分组。 |
| 测试延迟 | 单点或批量测试，使用诊断内核，即使主代理停止也能测。可查看最近延迟、24 小时可用率等监测结果。 | 内置内核支持单点、批量、草稿节点及整链测试，可查看历史样本与可用率。 |
| 添加与编辑 | 可添加自定义 HTTP、HTTPS、SOCKS5 节点，填写服务器、端口和认证信息。订阅节点支持本地改名、改地址和端口、恢复订阅值。 | 自定义节点支持填写服务器、端口及凭据并测试，订阅节点可保存本地修改或在本地隐藏。 |
| 分组 | 来源树展示订阅分组。可编辑订阅组的名称、策略和成员，创建自定义分组及子分组，重命名、移动或删除自建分组，批量维护成员。 | 可查看订阅分组，创建手动分组或按来源、延迟上限及成员数自动筛选的分组，可预览成员、配置选路策略和选择分组出站。 |
| 链路 | 在链路面板按顺序选择前置、中转、出口，保存、命名、加载、删除和测试整链。可通过分流规则将指定 Windows 程序交给链式出口。 | 可创建和命名多跳链路，选择并调整各跳节点，保存、选择为出口、测试整链或删除。 |

单节点测速只经过待测节点。整链测速按保存的顺序经过各跳。测试目标、预期 HTTP 状态码和监测间隔在「设置 → 后台监测」中调整。节点能否连通还取决于本机到服务器的网络、凭据、协议和测试目标。

### 节点详情与页面状态

Windows 的节点详情可对单个节点测速、查看统计和编辑本地覆写。分组树可收起并调整宽度；卡片密度、勾选的节点和后台监测偏好会保存。Android 的节点编辑页可调整参数、单独测试和恢复订阅值。来源筛选、当前出口、自建分组与已保存链路各自维护。

测速配置与正式连接都需要带入所属订阅的顶层 `hosts`，包括同一主机的多个 IPv4／IPv6 地址。地址个数不会增加节点数量。

## 连接日志

仪表盘提供实时连接摘要。「连接日志」显示应用、目标、上下行流量和出站链路，可以搜索和筛选记录，在诊断区查看路径与探测结果。两端在系统能识别进程或应用包时显示名称及图标。Android 还可以查看命中规则、区分进行中与已结束的连接，并单独断开活动连接。

| 区域 | 阅读和操作方式 |
| --- | --- |
| 实时表或卡片 | 目标可显示为域名或 IP 和端口。Windows 仪表盘分别列出每条连接的下载量和上传量；连接日志的「累计流量」为两者之和。悬停在数值上或选中记录可查看上下行明细。整链探测的耗时保留在诊断详情中。系统能识别应用时显示应用名和图标。 |
| 搜索和筛选 | 可按关键词和「全部」「已连通」「异常」缩小范围。Android 的异常筛选可查看失败的整链探测。 |
| 连接诊断 | 选择记录查看目标和出站路径。Android 可查看命中规则和断开活动连接。Windows 可查看整链探测阶段、已验证出口、耗时或失败原因。 |

## 设置

| 设置项 | 可用操作与平台差异 |
| --- | --- |
| 启动（Windows） | 可分别设置登录 Windows 时打开 Air、打开 Air 时总是启动代理。关闭后一项时，下次启动恢复上次退出前的代理状态、模式和已保存出口。关闭窗口可收进托盘，从托盘退出才结束程序。 |
| 主题 | 两端支持跟随系统、浅色和深色。 |
| DNS 设置 | 管理主 DNS、引导 DNS、直连 DNS、节点 DNS、备用及分域 DNS。可从订阅读取解析地址、使用加密 DNS、测试解析，选择真实 IP 或 Fake-IP 模式并配置排除域名、缓存、hosts 和 IPv6 解析。 |
| 虚拟网卡（TUN） | 调整协议栈、MTU、DNS 接管及绕过网段。Windows 还可设置严格路由。Android 的设备级接管由系统 VPN 服务完成，绕过网段需要 Android 13 及以上。 |
| 代理接入 | 设置 HTTP/SOCKS 混合端口、局域网访问、IPv6 和 TCP 并发。Windows 可另设系统代理绕过列表，Android 可留空关闭本地混合端口。 |
| 分流规则 | 选择订阅规则来源，配置规则启用状态和优先顺序，预览编译结果和默认出口。先匹配自定义规则，再处理继承的订阅规则，最后使用默认出口。支持域名、域名及子域名、IP 或网段，Windows 另支持进程名称或路径，Android 10 及以上支持应用包名。出站可选直连、拒绝、可用分组或链路等。 |
| 诊断内核 | Windows 检测随包内核，也可选择本机 Mihomo 路径。Android 可检查内置内核版本和当前配置。 |
| 后台监测 | Windows 收起窗口后可以自动测速。Android 可启用系统安排的定时测速，间隔至少 15 分钟，结果回到应用后合并。此间隔与订阅同步间隔分别设置。 |
| 配置文件 | 可直接编辑 Air 的全局 YAML、校验并保存。Windows 支持打开目录、重读文件、冲突检测和上一版备份。Android 可通过设置编辑网络、分流和监测配置。 |
| 关于与软件更新 | 可查看版本和作者主页。Windows 支持启动及后台检查、查看发布说明、下载并安装更新。Android 可以检查新版本并打开发布页面。 |

### Windows 配置示例

网络和测速参数写在 `network` 段，分流写在 `routing` 段。旧文件可能只有 `routing`。下面展示的是主 DNS 和后台测速间隔，已有 `network` 时直接修改其中的字段。

```yaml
network:
  nameserver:
    - https://223.5.5.5/dns-query
    - https://doh.pub/dns-query
  probeIntervalMinutes: 15
```

表单保存前会将上一次的完整原文写入同目录的 `air-config.previous.yaml`，其中包含手写注释。遇到外部修改冲突时，重新读取后再保存。订阅和测速历史由 `air.sqlite3` 管理，自定义分组在 `custom-groups.json`，这些数据通过各自的页面维护。

```yaml
routing:
  inheritRules: false
  fallback: { kind: direct }
  rules:
    - matcher: domainSuffix
      value: corp.example.com
      target: { kind: direct }
    - matcher: processPath
      value: 'C:\Program Files\Google\Chrome\Application\chrome.exe'
      target: { kind: residential }
```


## 跨平台实现与验收

下表用于在新平台移植一页后核对结果。每项都可以用独立测试订阅和本地配置验证。

| 页面 | 验收示例 |
| --- | --- |
| 仪表盘 | 选择节点并启动，核对出站模式和流量。切换出口后重新检查出口 IP，回到仪表盘应复用同一出口的检测结果。点击出口检测入口可手动重试。 |
| 订阅 | 分别通过 URL、二维码和文件导入，核对预览、确认后的列表和重启后的名称。用两个同名链接检查记录独立。手动改名再同步，保留自定义名。修改本地 YAML 后核对自动更新状态。模拟一次下载失败，核对上次配置仍可使用。 |
| 节点库 | 在主代理停止时分别进行单点、批量和整链测速。准备一个双栈主机别名并检查测速配置、连接配置和节点数量。设置当前出口，再切换页面检查所选出口。 |
| 分组和链路 | 创建分组、加入节点；建立至少两跳的链路，核对跳序、整链测速与运行路径。删除所引用的订阅后检查相关规则与可用出口。 |
| 连接日志 | 发起已知目标的请求，核对目标、出站路径和流量，检查无记录、筛选无匹配和停止代理时的显示。能识别应用时核对应用名及图标。 |
| 设置 | 保存后重新打开检查持久化。运行时切换规则、全局和直连，用同一目标核对实际路由。按平台分别检查开机启动或 VPN 授权、后台更新、配置文件和应用更新入口。 |

Windows 的页面实现在 [仪表盘](../src/features/home/Dashboard.tsx)、[订阅](../src/features/subscriptions/Subscriptions.tsx)、[节点库](../src/features/nodes/NodeLibrary.tsx)、[连接日志](../src/features/connections/ConnectionsPage.tsx)和[设置](../src/features/settings/SettingsView.tsx)。Android 对应的[主页和列表](../android/web/src/views.tsx)、[导入与编辑页](../android/web/src/workflows.tsx)、[设置](../android/web/src/settings.tsx)和[网络设置](../android/web/src/network-settings.tsx)可以逐项对照。

## 设计原型导航

桌面画板从上往下分为六组。

1. 首页、订阅与 YAML 编辑
2. 节点库与视图
3. 节点与分组编辑
4. 链路管理
5. 连接日志与设置
6. 订阅导入、来源编辑与删除确认

手机画板位于桌面画板右侧。第一排是五个主导航页面，第二排展示添加节点、分组、链路、列表、主题和 YAML 编辑器，第三排展示所选订阅的内容、导入和编辑操作。
