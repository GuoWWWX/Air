# Air 功能需求文档目录

本目录用于集中沉淀 **Air 代理客户端（Windows 桌面版 / Android 手机版）** 各个核心功能模块的产品需求、业务规则与交互规范，作为后续设计评审、双端功能对齐与版本验收的统一依据。

## 核心产品理念

1. **不自造私有标准，兼容并灵活编排行业标准**：底层完全遵循 Clash / Mihomo 标准规则语法、代理组机制（`select` / `url-test` / `fallback` / `load-balance`）与 `rule-providers`，让各类现成订阅和通用规则能够开箱即用。
2. **节点管理与规则管理解耦后灵活组合**：支持多订阅、自定义分组、自定义节点与多跳链路自由测试和切换，同时把订阅自带规则与用户自建规则统一管理，支持默认自动跟随或按需显式绑定。
3. **规则生效透明可观测**：任何流量最终走了哪条规则、从哪个真实出口节点出去，均可在「实时连接」与「连接日志」中清晰查看并快速调整策略。
4. **双端核心语义统一**：Windows 桌面端与 Android 手机端在规则优先级、绑定逻辑和主要交互体验上保持一致。
